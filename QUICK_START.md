# 🚀 Quick Start - ECM Digital

## 📦 Co masz w tym projekcie?

### 1. **Główna strona ECM Digital**
- Portfolio agencji
- Oferta usług
- Formularze kontaktowe / Calendly
- **Port:** 3001 (Next) lub statyczny `public/` na Vercel

### 2. **Client Dashboard** (Next.js)
- Panel dla klientów
- Zarządzanie projektami
- Komunikacja z zespołem
- Tryb demo (localStorage)
- **Port:** 3002

## 🎯 Szybki Start

```bash
# 1. Zainstaluj zależności
cd ecmdigitalwebsite
npm install

cd client-dashboard
npm install

# 2. Uruchom główną stronę
cd ..
npm run dev
# Otwórz: http://localhost:3001

# 3. Uruchom dashboard (w nowym terminalu)
cd client-dashboard
npm run dev
# Otwórz: http://localhost:3002
```

**✅ Gotowe!** Obie aplikacje działają w trybie demo.
